# webnace

Catálogo web simple para IMPORTPY — Especial Día del Niño 2026.

Contenido:
- `index.html` — página principal
- `css/style.css` — estilos
- `js/script.js` — scripts
- `imagenes/` — imágenes del catálogo

Instrucciones rápidas:
```powershell
git init
git add .
git commit -m "Inicial: proyecto webnace"
git remote add origin https://github.com/naceimportpy-tech/webnace.git
git branch -M main
git push -u origin main
```
